VRChat 월드 내 언어 안내 포스터, 디스코드 커뮤니티 역할(Role) 아이콘, 이모티콘, 자막 오버레이 등

**밝은 배경과 어두운 배경 모두에서 그대로 잘 보이도록** 디자인되었습니다.

> [!IMPORTANT]
> **어떤 파일을 받아야 하나요?**
> - **PNG** — 국기 패턴까지 모두 포함된 **완성본**입니다. 대부분의 경우 이 파일을 사용하시면 됩니다.

>   국기 패턴을 외부 이미지로 참조하고 있어, 단독으로 열면 **윤곽선만 표시**됩니다.
>   색상까지 포함된 편집이 필요하시다면 아래 일러스트레이터 원본(.AI)을 이용해 주세요.

> 📦 **일러스트레이터 원본 (.AI):** 벡터 편집용 원본은
> [`assets/vector/sign_language_badges.ai`](./assets/vector/sign_language_badges.ai) 에서 내려받으실 수 있습니다.

## 📋 사용 방법 (Markdown Snippets)

깃허브 프로필, README, 블로그, 노션 등에 **그대로 복사해서 붙여 넣으면 됩니다.**
아래 코드는 모두 이 저장소의 `main` 브랜치를 직접 참조하는 절대 경로를 사용합니다.

### ① 가장 간단한 방법 — 마크다운 한 줄

```markdown
![KSL](https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/KSL.png)
```

`KSL` 부분을 `ASL`, `BSL`, `DGS`, `JSL`, `Libras`, `LSF`, `NGT` 중 원하는 약어로 바꿔 주세요.

### ② 크기를 지정하려면 — HTML `<img>`

```html
<img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/KSL.png" height="36" alt="Korean Sign Language"/>
```

`height` 값만 지정하면 가로 비율은 자동으로 유지됩니다.
권장값은 프로필 배지 `28`, 본문 `36`, 헤더 `64` 입니다.

### ③ 여러 배지를 한 줄로 나열하기

```html
<p align="center">
  <img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/KSL.png" height="36" alt="KSL"/>
  <img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/ASL.png" height="36" alt="ASL"/>
  <img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/BSL.png" height="36" alt="BSL"/>
  <img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/JSL.png" height="36" alt="JSL"/>
</p>
```

### ④ 클릭하면 저장소로 이동하는 배지

```markdown
[![KSL](https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/KSL.png)](https://github.com/LeeSimYul/sign-language-badges)
```

### ⑤ 출처 표기까지 포함한 완성형 블록 (복사 권장 ✅)

```html
<p align="center">
  <img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/KSL.png" height="36" alt="Korean Sign Language"/>
  <br/>
  <sub>
    Sign Language Badges by
    <a href="https://github.com/LeeSimYul/sign-language-badges">LeeSimYul</a> ·
    <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>
  </sub>
</p>
```

> [!TIP]
> 배지는 **배경이 투명한 PNG** 이므로 밝은 테마와 어두운 테마 모두에서 그대로 사용하실 수 있습니다.
> 디스코드 역할 아이콘처럼 정사각형이 필요한 경우에만 여백을 조금 더해 주세요.

## 🤝 기여하기

새로운 수어 배지 기여를 언제나 환영합니다.
디자인 규격, 폰트 가이드, 파일 네이밍 규칙 등 자세한 내용은

요약하면 다음과 같습니다.

1. `assets/png/<약어>.png` 에 배경이 투명한 완성본 PNG 추가 (가로세로비 약 2:1)
2. `assets/svg/<약어>.svg` 에 외곽선 벡터 추가 (글자는 **아웃라인 변환 필수**)
3. README 표(국문/영문 양쪽)에 행 추가 후 Pull Request

# 🌐 English

**Open-source typographic badges pairing each sign language's abbreviation with its national flag pattern**

[한국어로 돌아가기 ↑](#-global-sign-language-typo-badges)

</div>

### About

Hand-made open graphics that fill bold lettering with each country's flag pattern.
Use them freely in VRChat world signage, Discord role icons and emoji, subtitle
overlays, documentation, or anywhere else.

Every badge carries a white outer keyline around a flag-filled letterform, so a
single file reads cleanly on **both light and dark backgrounds** — no separate
dark-mode asset is needed.

> Missing the sign language you need? Open an
> [issue](https://github.com/LeeSimYul/sign-language-badges/issues) or read the
> [contributing guide](./CONTRIBUTING.md) and add it yourself. Auslan, LSE, CSL,
> ISL and LIS are all still waiting for someone.

> - **PNG** — the **finished badge**, flag pattern included. Use this unless you have a reason not to.
> - **SVG** — the vector letter outlines. The SVGs for `ASL`, `BSL`, `DGS`, `Libras` and `NGT`
>   reference their flag pattern as an external image, so on their own they show
>   **outlines only**. For full-colour editing, use the Illustrator master below.

### Markdown snippets

Copy any of these straight into your GitHub profile, README, blog or Notion page.
Every snippet points at absolute URLs on this repository's `main` branch.

**① Simplest — one line of Markdown**

```markdown
![ASL](https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/ASL.png)
```

Swap `ASL` for `BSL`, `DGS`, `JSL`, `KSL`, `Libras`, `LSF` or `NGT`.

**② Sized — HTML `<img>`**

```html
<img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/ASL.png" height="36" alt="American Sign Language"/>
```

Set `height` only and the aspect ratio follows. Suggested: `28` for a profile
badge, `36` in body text, `64` for a header.

**③ A row of badges**

```html
<p align="center">
  <img src="https://raw.githubusercontent.com/LeeSimYul/sign-language-badges/main/assets/png/ASL.png" height="36" alt="ASL"/>

</p>
```

### Contributing

New sign language badges are always welcome. See **[CONTRIBUTING.md](./CONTRIBUTING.md)**
for the design specification, typography guide and naming rules (Korean and English).

1. Add a finished transparent PNG at `assets/png/<ABBR>.png` (roughly 2:1)
2. Add the outline vector at `assets/svg/<ABBR>.svg` (**all type converted to outlines**)
3. Add a row to both README tables and open a pull request
