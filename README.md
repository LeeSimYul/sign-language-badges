## 🌍 Global Sign Language Typo Badges

각국의 수어 약어(Acronym)와 국기 패턴을 결합하여 직접 제작한 일러스트 배지 자산입니다.  
디스코드 역할(Role) 아이콘, 커뮤니티 이모티콘, VRChat 월드 내 언어 안내 포스터 등에 자유롭게 활용하실 수 있습니다.

| **DGS** | Deutsche Gebärdensprache (독일 수어) | 독일 국기 | 디스코드 역할, UI 배지 등 |

| **KSL** | Korean Sign Language (한국 수어) | 태극 문양 (한국) | 디스코드 역할, UI 배지 등 |
| **Libras** | Língua Brasileira de Sinais (브라질 수어) | 브라질 국기 | 디스코드 역할, UI 배지 등 |
| **LSF** | Langue des Signes Française (프랑스 수어) | 삼색기 (프랑스) | 디스코드 역할, UI 배지 등 |
| **NGT** | Nederlandse Gebarentaal (네덜란드 수어) | 네덜란드 국기 | 디스코드 역할, UI 배지 등 |
