## 🌍 Global Sign Language Typo Badges

각국 수어를 상징하는 국가 패치와 알파벳 타이포그래피를 결합하여 직접 제작한 오픈소스 그래픽 자산입니다.  
VRChat 월드 내 언어 안내 포스터, 디스코드 커뮤니티 역할(Role) 아이콘, 이모티콘 등 자유롭게 활용하실 수 있습니다.
